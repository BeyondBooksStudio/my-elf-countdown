# My Elf Countdown

A private, parent-managed Christmas countdown planner.

**Login and data now run on Supabase** (email and password for parents). Start with `SUPABASE_SETUP.md`.

- `pnpm dev`: development server (needs a `.env`; see `.env.example`).
- `pnpm build` / `pnpm start`: build and serve.
- `pnpm check` / `pnpm test`: types and tests.
